Bu dastur — o'quv tizimini boshqarish uchun yozilgan konsol dasturidir.
U orqali quyidagi ishlarni bajarish mumkin:
O'quvchi qo'shish
O'qituvchi qo'shish
Kurs yaratish
Kursga o'quvchi qo'shish yoki olib tashlash
Kurs o'qituvchisini almashtirish
Barcha ro'yxatlarni (o'quvchi, o'qituvchi, kurslar) ko'rish
Ya'ni dastur o'quv jarayonidagi asosiy ma'lumotlarni — o'quvchi, o'qituvchi va kurslarni boshqarish uchun mo'ljallangan.
